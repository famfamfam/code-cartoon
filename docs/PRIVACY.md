# Privacy

code-cartoon is a set of instructions, templates and scripts that run on your computer inside
Claude Code.

- **No data leaves your machine because of this skill.** Drawing, rendering, sound synthesis and
  narration (Piper or the system voice) run locally. There is no telemetry, no analytics and no
  account.
- **Network access** happens only when you install things: `npx` downloads HyperFrames, HyperFrames
  downloads a headless Chrome, `pip` installs Python packages and Piper, and Piper downloads a voice the
  first time you use it.
- **Your photos and drawings** stay in the project folder you choose. The skill tells Claude to treat
  photos of real people, especially children, as private and never to publish or upload them.
- **Claude Code itself** sends your conversation to the model provider as usual; that is governed by
  your Claude Code agreement, not by this skill.

Questions: open an issue at https://github.com/famfamfam/code-cartoon/issues.
