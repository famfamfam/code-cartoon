# code-cartoon

[English](README.md) · Русский

Скилл для Claude Code, который делает анимационные ролики кодом. Вы описываете историю. Claude задаёт
несколько вопросов, пишет раскадровку и рисует каждый кадр как функцию времени на HTML canvas (или в
Three.js для 3D). Затем он рендерит MP4 через [HyperFrames](https://github.com/heygen-com/hyperframes)
и синтезирует звук по тем же таймингам. Видеонейросети здесь не участвуют: карандашные линии,
штриховка, бумага и музыка — это код, и всё работает на вашем компьютере.

Сделано для [6io.io](https://6io.io).

Эти пять роликов идут в комплекте: `cartoon example <имя>` собирает любой из них заново (клип поётся
под синтезированную демо-песню), а готовые MP4 приложены к [релизам](https://github.com/famfamfam/code-cartoon/releases).

Настоящий клип, сделанный этим навыком: **[Steel Wings](https://github.com/famfamfam/code-cartoon/releases/download/v1.2.0/Steel-Wings-Ela-Sixio.mp4)** (MP4, 82 МБ, со звуком), воздушный бой
Второй мировой в 3D цветным карандашом под инструментал Ela & Sixio, 2:37, сделан по одному треку.

## Что можно сделать

| Стиль | Палитра / шаблон | Как выглядит |
|---|---|---|
| Карандаш, неон, мистика | `graphite`, `neon`, `mystic` | набросок «на двойках» с кипящими линиями и штриховкой |
| Мел, синька, тетрадь, крафт, тушь | `chalk`, `blueprint`, `notebook`, `kraft`, `ink` | бумага, линия и штриховка своего материала |
| Детский рисунок мелками | `crayon` | восковые каракули, белые ореолы, контур фломастером |
| Лубок / Билибин | `lubok` | плоский цвет, жирный контур, волны-завитки, орнаментальные рамки, ленты |
| Ретро-растр, газетный коллаж | `retro`, `collage` | точки печати, несовмещение, рваная бумага |
| Стекло и хром 3D | `--template 3d` | материалы Three.js, частицы, логотипы |
| 3D цветным карандашом | `engine/pencil3d.js`, `sky`, `storm`, `dusk` | самолёты, машины и кучевые облака в настоящем 3D, нарисованные цветным карандашом с «кипящим» контуром; симуляция полёта для погонь и воздушных боёв |
| Фото + 3D | `--template photo3d` | ваше фото с «живой» камерой, рисунок-раскладушка, 3D-мир |
| Гибрид с ротоскопом | любая | снятое или сгенерированное видео, перерисованное в стиль |
| Клип на песню | `--template clip` | части вашей песни (Suno, Udio, своя, в том числе без слов) — разные миры, текст пишется по мере пения, нарезка для Reels |

Одна раскадровка, любой формат: 9:16, 16:9, 1:1, 4:5. Шестнадцать палитр; ролик перекрашивается одной
строкой. Все палитры на одном кадре: [`skills/code-cartoon/assets/themes.jpg`](skills/code-cartoon/assets/themes.jpg).

## Как это работает

1. **Сначала вопросы.** Сюжет, стиль, формат, длина, текст и его язык, звук. В каждом пакете вопросов
   есть вариант «хватит спрашивать, решай сам».
2. **Раскадровка.** Таблица `время | что рисуется | камера | звук`: один поворот на 35–45 % длины,
   в последние три секунды — постер.
3. **Код.** Время каждого события лежит в `cues.js`. Его читает и сцена (`d.cue("twist")`), и синтезатор
   звука, поэтому картинка и звук не расходятся.
4. **Самопроверка.** Прежде чем что-то показать, Claude снимает кадры, смотрит лист кадров и крупные
   вырезки и запускает детектор скачков и дрожания.
5. **Рендер и сдача.** MP4 24 кадра/с, громкость −15 LUFS, лёгкая копия для мессенджеров и честная
   приписка, что не проверено.

## Что нужно

- [Claude Code](https://code.claude.com)
- Node.js 22+ и FFmpeg
- Python 3.9+ с `numpy`, `scipy`, `pillow`
- HyperFrames при первом рендере скачивает headless Chrome (около 150 МБ).
- По желанию, для голоса рассказчика: `pip install piper-tts`. Без него работает системный голос
  Windows, macOS или Linux (`espeak-ng`).
- На Windows нужен Git Bash; Bash-инструмент Claude Code уже его использует.

Проверить всё сразу: `skills/code-cartoon/scripts/cartoon doctor`.

## Установка

Как плагин из маркетплейса этого репозитория:
```bash
claude plugin marketplace add famfamfam/code-cartoon
claude plugin install code-cartoon@famfamfam
```
В сессии то же самое делают `/plugin marketplace add famfamfam/code-cartoon` и
`/plugin install code-cartoon@famfamfam`. Скилл вызывается как `/code-cartoon:code-cartoon` и сам
включается, когда вы просите мультик.

Или скопируйте только скилл (он станет `/code-cartoon`):
```bash
git clone https://github.com/famfamfam/code-cartoon
cp -R code-cartoon/skills/code-cartoon ~/.claude/skills/
```

## Быстрый старт

Просто попросите, на любом языке:

```text
Сделай 10-секундный рилс 9:16 карандашом: из семечка вырастает дерево, в конце надпись «Расти каждый день».
```
```text
/code-cartoon сказка на 40 секунд по рисунку сына, в стиле лубка, с голосом рассказчика
```
```text
Заставка 16:9 для подкаста, стекло и хром, под эту песню: audio/theme.mp3
```
```text
Сделай клип на мою песню из Suno: song.mp3, рядом текст с метками и стем вокала. Полный клип 16:9 и припев для Reels.
```

Рабочие файлы каждого ролика — обычная папка: `index.html`, `scene.js`, `cues.js`, `project.md`
(сюжет и раскадровка), `audio/mix.wav` и MP4.

## Команда `cartoon`

Все шаги идут через один скрипт. Он находит настоящий Python на любой ОС, закрепляет версию
HyperFrames и держит консоль в UTF-8. Сами вы его почти не набираете — это делает Claude.

| Команда | Что делает |
|---|---|
| `cartoon new <папка> --format 9:16 --duration 12 --palette neon --template 2d\|3d\|photo3d` | новый проект; стартовая сцена работает в любом формате |
| `cartoon new <папка> --template clip --song s.mp3 --lyrics l.txt --vocals v.wav` | клип на песню: части песни и строки текста по времени, карта песни и караоке-предпросмотр |
| `cartoon song --lrc audio/song.lrc` | заново расставить строки по исправленному LRC (или `--auto`) |
| `cartoon cut reel --auto --format 9:16` | нарезка клипа (припев для Reels) отдельным проектом |
| `cartoon example [имя] [папка]` | список или сборка примера из комплекта |
| `cartoon lint` / `snapshot --at 0,3.9` / `render --output out.mp4` | HyperFrames проверенной версии |
| `cartoon audio` | эффекты + настроение музыки + голос + ваши дорожки -> `audio/mix.wav` |
| `cartoon voice --fit` | озвучить реплики; длина титров подстраивается под речь |
| `cartoon beats song.mp3 --snap cues.js` | темп, доли, такты, энергия; события в долю |
| `cartoon check out.mp4 --duration 10 --fps 24 --size 1080x1920` | длина, fps, размер, громкость, пик, первый и последний кадр |
| `cartoon frames out.mp4 --zoom` / `--twitch` / `--jumps` | крупные вырезки, дрожащие детали, незапланированные скачки |
| `cartoon sheet out.mp4` / `cartoon share out.mp4 --gif` | лист кадров; лёгкие MP4 и GIF/WebP |
| `cartoon analyze ref.mp4` / `cartoon roto clip.mp4 .` | разбор референсов; гибрид с ротоскопом |
| `cartoon doctor` / `cartoon selfcheck` | проверка машины; проверка самого скилла |

## Звук

- 17 синтезированных эффектов: карандаш, штриховка, ластик, «чпок», вжух, звон, перелистывание, гул
  ракеты, волшебство, ветер и другие. Каждый стоит на своём событии.
- Настроения музыки: `musicbox` (шкатулка), `folk` (щипковые струны над бурдоном), `space`. На
  повороте музыка становится тёплой.
- Голос рассказчика: [Piper](https://github.com/OHF-Voice/piper1-gpl) (русские и английские голоса,
  локально), системный голос или ваши записи. Музыка приглушается под речь.
- Ваша песня: `cartoon beats` находит доли и дроп и ставит события в сетку.
- Клип на песню: `cartoon song` находит части песни (по меткам текста, музыке и голосу), ставит каждую
  строку текста по времени (по стему вокала, файлу LRC или по тактам) и делает караоке-предпросмотр,
  чтобы проверить тайминг до рендера. Картинка привязана к долям.
- Сведение нормализуется до −15 LUFS с пиком не выше −1 dBFS.

## Ограничения

- Нет фотореализма и живой мимики. Реальный человек появляется как настоящее фото (шаблон фото + 3D),
  а не как поддельная 3D-модель.
- 3D кодом — это частицы, геометрия, материалы, игрушечные объекты и нарисованные карандашом машины
  и облака, а не полнометражная анимация.
- Живое движение — через гибрид с ротоскопом: снятый или сгенерированный где-то ещё клип,
  перерисованный в стиль.
- Время рендера на ноутбуке: около 40 с на 8 с 2D в 1080p, около 3,5 мин на 40 с фото + 3D,
  11–16 мин на клип в 2,5 минуты с карандашным 3D. Длинные ролики собираются из сцен по 10–30 с и
  показываются по этапам: ключевые кадры, черновик каждой части, потом полный рендер.
- Рендерер — HyperFrames 0.8.164; с другими версиями могут понадобиться мелкие правки.

## Приватность

Всё работает локально: рисование, рендер, звук и озвучка. Скилл никуда ничего не отправляет и не
собирает телеметрию. Сеть нужна только для установки зависимостей, headless Chrome и голосов Piper.
Фото людей, особенно детей, скилл считает личными и не публикует. Подробнее: [docs/PRIVACY.md](docs/PRIVACY.md).
